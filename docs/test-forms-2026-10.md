# Комплект тестов от 26 октября 2026

Локальная версия заменяет прежние шесть форм материалами заказчика. Учётные записи, организации, подразделения и кампании сохраняются. Сброс старых прохождений выполнен только в локальной базе после резервного копирования.

| Направление | Состав | Лимит |
|---|---|---|
| Вербальный анализ | 8 текстов, 30 заданий, 2 тренировочных | 22 минуты |
| Числовая информация | 6 таблиц, 18 заданий, 2 тренировочных | 25 минут |
| Абстрактная логика | 24 матрицы OMIB, 2 тренировочных | 20 минут |
| Личностный профиль | 120 пунктов и 6 контрольных | Без ограничения |
| Мотивация | 48 пунктов, 12 шкал, выбор 3 наиболее и 3 наименее важных факторов | Без ограничения |
| Управленческие ситуации | 14 кейсов и 1 тренировочный | 30 минут |

Инструкция и тренировка проходят до запуска таймера. После начала можно пропускать задания и возвращаться. При истечении лимита сервер автоматически завершает тест и рассчитывает сохранённые ответы, пропуски дают ноль. Опросники без таймера требуют всех ответов. Приоритеты обязательны для завершения мотивационного опросника.

Язык вопросов, материалов и ответов меняется общим переключателем RU/KK. Русские формулировки извлечены из документов. Казахский перевод рабочий и требует проверки специалистом.

Сотрудник видит только назначения и прохождение тестов. После завершения всех назначенных направлений показывается экран с зелёной галочкой и предложением уточнить результаты у администратора. Раздел результатов, анализ, формирование и скачивание отчётов сотруднику недоступны, включая прямые API-запросы и старые ссылки. Возможности администратора и эксперта сохранены. Проверка сценария: `npx tsx tests/employee-completion.ts`.

Время продолжает идти при обычном выходе из страницы теста. Открытая страница подтверждает связь каждые 5 секунд. При отсутствии подтверждений более 15 секунд сервер фиксирует паузу от последнего ожидаемого подтверждения. После восстановления связи срок продлевается на паузу. Закрытие страницы передаёт отдельное событие выхода. Принудительное завершение браузера без события выхода технически неотличимо от потери связи и также может привести к паузе.

Ответы сохраняются очередью с ревизиями. Несохранённая очередь хранится на устройстве до подтверждения сервером, восстанавливается после перезагрузки и не перезаписывает отличающийся ответ другой вкладки.

Контрольные личностные пункты исключены из сумм. При двух и более категориях признаков качества интерпретация опросника ожидает решения назначенного эксперта. Остальные результаты доступны. Эксперт принимает результат или назначает повторное прохождение с обязательным обоснованием. Контрольные признаки не показываются сотруднику. Шкала N и фасета N3 развёрнуты в устойчивость.

Мотивация рассчитывается по двенадцати средним, с обратным кодированием, вычитанием среднего участника и поправкой +0,5/−0,5 по карточкам. При равенстве итогового значения на границе топ-3 сохраняются все равные приоритеты. Это не создаёт искусственных различий.

Сравнение внутри кампании доступно при наличии минимум двух сопоставимых завершённых результатов. Используются одна форма и один ключ, процентиль равен доле результатов строго ниже текущего. Это внутригрупповое сравнение, не внешняя норма. Профили, ожидающие проверки качества, исключены из сравнения и автоматической интерпретации.

Пороги уровней способностей и SJT предварительные. В числовом тесте используются диапазоны сырых баллов документа; процент рассчитывается математически, без ошибочных процентных границ из таблицы. Пороговые категории личности не присваиваются в промежутках, не определённых документом; показываются фактические средние.

Матрицы OMIB отобраны по исходной таблице параметров. Изображения сверены с исходными кодами; варианты построены на типичных ошибках применения правил. Подборка и дистракторы требуют независимой методологической проверки и пилота. Ключ нового ситуационного теста хранится как предварительный. Автоматического статуса научной валидации нет.

## Обновление и проверка

Готовый каталог находится в `data/catalog.json`, исходная извлечённая форма — в `data/new-forms.json`, словарь перевода — в `data/forms-kk.json`. Старый генератор заменён входной точкой нового комплекта.

```powershell
npx prisma migrate deploy
npx prisma generate
npx tsx scripts/install-new-forms.ts
npm test
npx tsx tests/new-forms-integration.ts
npx tsx tests/new-forms-browser.ts
npm run dev
```

`install-new-forms.ts --local-reset` удаляет прохождения и отчёты заменяемого комплекта и назначает новые формы тем же участникам. Команда допускается только для локальной базы; её нельзя использовать для обычного обновления с сохранением новых результатов.

Для согласованной замены старого комплекта на сервере сначала сохраните резервную копию БД и остановите только API AssessFlow. Проверьте план командой `npx tsx scripts/install-new-forms.ts --replace-legacy-assignments --organization-id=<ID> --dry-run`, затем выполните её без `--dry-run`. Она заменяет назначения версий `*-v1` на `*-v2` в указанной организации, удаляет прежние прохождения и связанные отчёты, сохраняя аккаунты, настройки, файлы и практические наблюдения. Если у того же участника уже есть назначения новых форм, транзакция отменяется. Повторный запуск после успешной замены не сбрасывает новые результаты.

Для повторного извлечения русских материалов нужны оригинальные DOCX в Downloads:

```powershell
py -3.9 -X utf8 scripts/build-new-tests.py
npx tsx scripts/complete-new-forms.ts --translate
```

Перевод использует серверную настройку OpenRouter. Ключ не попадает в каталог и исходный код.
